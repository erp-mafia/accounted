# Reference materials

Versioned upstream documents used to validate generated accounting reports:

- `bokslut/taxonomi/`: taxonomy package and element lists consumed by `npm run taxonomy:generate` and checked by `npm run taxonomy:check`.
- `bokslut/exempel/`: the official annual-report example used by the iXBRL golden tests.

Keep these files byte-identical to their upstream originals. They are maintained build and test inputs.
