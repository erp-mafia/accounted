The re-read needs no new rule: a year with a booked IB is the continuation case already admitted since 2026-10-16 (the review step defaults the IB toggle off, the file's IB is compared, never booked). The "booked IB differs" advice no longer says to correct the IB "innan du importerar", which sent the same user out of the import a second time; correcting the IB verifikat afterwards in an open year touches none of the imported vouchers. The File object is held in page state only (no storage path reuse, no URL param), so a reload falls back to uploading again.
