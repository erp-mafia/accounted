[2026-10-21] Stripe Checkout prefill (PH 191): the company's name, address, org number (custom invoice field, legal persons only; never an enskild firma personnummer) and stored VAT number (Stripe type eu_vat, since Stripe has no se_vat) are written onto the existing or just-created Stripe customer as a best-effort sync after the create-or-reuse step, rather than inline at customer creation: any Stripe or read error falls back to the old Checkout flow, so a prefill problem can never block a payment. The VAT number is never derived from the org number (a registered company without a stored number gets none, and Checkout still offers the field), and a tax ID the customer already has is kept, not replaced.
