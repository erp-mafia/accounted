[2026-11-13] MCP tool calls are mirrored to PostHog as `$mcp_tool_call` for every person, and the person's analytics switch decides whether the call is tied to them (founder decision 2026-11-13): with analytics on the event carries the user id and the company group; with analytics off it is counted without a user id, a company or a session id, under one shared distinct id and with `$process_person_profile` false. The privacy text names only error reports and arkiv events as sent with the user id "oavsett ditt val", so an opted-out person's agent calls are counted as an unnamed total instead of widening that sentence. Sandbox companies are never sent. The event carries a fixed field list (no arguments, results, messages or free text; an unrecognised tool name, a non-code error and a non-UUID session id are dropped) and sets `$mcp_source` to the value PostHog's own SDK sends, because PostHog's per-tool analytics filter on it; the server does not run that SDK and no dependency was added.
