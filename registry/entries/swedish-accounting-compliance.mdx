## Vad skillen täcker

* Bokföringslagen (BFL, SFS 1999:1078): bokföringsskyldighet, löpande bokföring och tidsfrister, verifikationer, rättelser, arkivering i 7 år, SFS 2024:342 (pappersoriginal får förstöras efter digitalisering sedan 1 juli 2024) och villkoren för att förvara räkenskapsinformation utomlands.
* Bokföringsnämndens allmänna råd (BFNAR): 2013:2 (Bokföring), 2016:10 (K2 Årsredovisning i mindre företag), 2012:1 (K3 Årsredovisning och koncernredovisning).
* BAS-kontoplanen: klassindelning, standardkonton, momskonton, BAS 2026-omläggningen (bland annat klass 4 och 12xx/78xx).
* Momsdeklaration: rutornas mappning till BAS 26xx, EU-handel, reverse charge.
* Verifikationer: vad som krävs per BFL 5 kap, vilka underlag (kvitto/faktura), original vs digital kopia.
* Skatteverket: arbetsgivaravgifter och AGI, F-skatt, skattekonto, momsregistrering, ROT/RUT.
* SIE4-formatet och systemdokumentation med behandlingshistorik (BFL 5 kap 11 §, BFNAR 2013:2 kap 9).
* Regeländringar 2024–2026 med datum: momsregistreringsgränsen 120 000 kr från 2025, livsmedelsmoms 6 % från 1 april 2026 till och med 31 december 2027, 3:12-reformen från inkomstår 2026, K2-ändringarna i BFNAR 2025:2 och tillfälligt sänkta arbetsgivaravgifter för unga.

Skillen är ett orakel som agenten konsulterar vid behov, inte ett
batterier-inkluderat-flöde. Den paras vanligen med en mer
operationell skill (typ [månadsbokslut-pa-en-fika](/community/registry/manadsbokslut-pa-en-fika))
som faktiskt utför arbete.

## Installera

```bash
git clone https://github.com/erp-mafia/accounted-skills.git
cd accounted-skills
claude
```

Skillen blir tillgänglig automatiskt i Claude Code när du jobbar
inne i mappen.

För att lägga till i ett befintligt projekt:

```bash
cp -r path/to/accounted-skills/.claude/skills/swedish-accounting-compliance \
      ./.claude/skills/
```

För Claude Desktop eller claude.ai: Settings → Customize (eller
Settings → Capabilities → Skills) och lägg till skill-filerna där.
Kräver att Code execution är aktiverat under Settings → Capabilities.

## Var skillen pluggar in

Triggar automatiskt på frågor som "är detta compliant?", "vad säger
BFL om X?", "vilka verifikat krävs för Y?", "K2 eller K3?", och
liknande. När agenten ser BFL, BFNAR, BAS-kontoplan, SIE4, K2/K3,
momsdeklaration, verifikationer, löpande bokföring eller
bokföringsskyldighet i kontexten laddar den skillen och svarar mot
regelverket istället för sin generella träningsdata.

Hög träffsäkerhet på saker som annars hamnar i hallucinationszonen:
exakta BFL-paragrafer, BFNAR-rådens scope, BAS-kontonas semantik per
klass, kraven på verifikationsserie och löpande numrering.
