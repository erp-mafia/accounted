## Vad det här är

Ett recept som du sätter upp själv. Posten pekade tidigare på n8n- och
Make-mallar som aldrig publicerades. Stegen nedan går mot accounteds
REST-API som det ser ut i dag och kräver bara `reports:read`. Inget skrivs
till huvudboken.

## Stegen

Kör på schema, till exempel första vardagen i månaden kl 08:00:

1. `GET /api/v1/companies/{companyId}/fiscal-periods`: ta `id` för räkenskapsåret. SIE-exporten omfattar alltid hela räkenskapsåret hittills och går inte att begränsa till en månad.
2. `GET …/reports/sie-export?period_id=…`: SIE4-filen som text (UTF-8) med kontoplan, ingående och utgående balanser, resultat och alla verifikationer. Lägg till `encoding=cp437` om revisorns program kräver det.
3. `GET …/reports/behandlingshistorik?period_id=…&from_date=…&to_date=…`: behandlingshistoriken som JSON. Datumen måste ligga inom räkenskapsåret, till exempel förra månaden.
4. `GET …/reports/balance-sheet/pdf?period_id=…&to_date=…` och `GET …/reports/income-statement/pdf?period_id=…&from_date=…&to_date=…`: rapporterna som PDF.
5. Räkna SHA-256 på SIE-filen och skicka filerna med din egen e-posttjänst, med summan i mejltexten.

Samma sak som skript:

```bash
BASE="https://app.accounted.se/api/v1/companies/$COMPANY_ID"
AUTH="Authorization: Bearer $ACCOUNTED_API_KEY"   # gnubok_sk_live_...

curl -s -H "$AUTH" "$BASE/fiscal-periods"
curl -s -H "$AUTH" -o bokforing.se \
  "$BASE/reports/sie-export?period_id=$PERIOD_ID"
curl -s -H "$AUTH" -o behandlingshistorik.json \
  "$BASE/reports/behandlingshistorik?period_id=$PERIOD_ID&from_date=2026-08-01&to_date=2026-08-31"
curl -s -H "$AUTH" -o balansrakning.pdf \
  "$BASE/reports/balance-sheet/pdf?period_id=$PERIOD_ID&to_date=2026-08-31"
curl -s -H "$AUTH" -o resultatrakning.pdf \
  "$BASE/reports/income-statement/pdf?period_id=$PERIOD_ID&from_date=2026-01-01&to_date=2026-08-31"
shasum -a 256 bokforing.se
```

Skapa API-nyckeln i app.accounted.se under Inställningar → API-nycklar och
ge den bara `reports:read`. Behandlingshistoriken som PDF, CSV eller Excel
laddar du ner i appen; API:t ger den som JSON.

## Allt i en zip: gnubok_audit_package

Vill du hellre ha ett komplett arkiv, be en agent med accounteds MCP-server
ta fram revisorspaketet för räkenskapsåret. `gnubok_audit_package` tar
`fiscal_period_id` och bygger en zip med:

```
bokforing.se                  # SIE4
rapporter/                    # saldobalans, resultat- och balansräkning, huvudbok (JSON + CSV),
                              # grundbok, momsdeklaration (JSON), bokslutsbilagor (PDF)
dokument/                     # underlagen till verifikationerna
bilagor/                      # bilagor till kontoavstämningar
revision/                     # behandlingshistorik och systemdokumentation
LÄSMIG.txt
```

Svaret är en signerad länk som gäller en timme. Med underlag får arkivet
vara högst 80 MB; blir det större, kör igen med `include_documents: false`.
Verktyget sparar zip-filen i accounteds lagring men ändrar inget i
huvudboken och skapar ingen väntande operation att godkänna.

## Begränsningar

* Bara bokförda verifikationer kommer med. Obokförda banktransaktioner och utkast syns inte.
* Ett räkenskapsår per anrop. Vid årsskiftet: skicka både det nya och det gamla året tills det gamla är stängt.
* Receptet räknar inte ut moms eller bokslut åt dig. För det, se [Månadsbokslut på en fika](/community/registry/manadsbokslut-pa-en-fika).
* Det följer inte upp om revisorn öppnar paketet.
