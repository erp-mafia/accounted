## Servern i korthet

Servern exponerar över 150 verktyg som en MCP-klient kan kalla. De grupperas
ungefär så här:

| Område | Exempel-verktyg | Server-side scope |
|---|---|---|
| Transaktioner | `gnubok_list_uncategorized_transactions`, `gnubok_categorize_transaction`, `gnubok_match_transaction_to_invoice` | `transactions:read` / `:write` |
| Fakturor | `gnubok_create_invoice`, `gnubok_send_invoice`, `gnubok_credit_invoice` | `invoices:write` |
| Leverantörer | `gnubok_list_suppliers`, `gnubok_create_supplier_invoice_from_inbox`, `gnubok_approve_supplier_invoice` | `suppliers:read` / `:write` |
| Rapporter | `gnubok_get_trial_balance`, `gnubok_get_balance_sheet`, `gnubok_get_income_statement`, `gnubok_get_vat_report`, `gnubok_vat_close_check`, `gnubok_get_kpi_report` | `reports:read` |
| Bokslut | `gnubok_year_end_readiness` (read), `gnubok_run_year_end`, `gnubok_close_period`, `gnubok_explain_voucher_gap` | `reports:read` / `bookkeeping:write` |
| Lön | `gnubok_create_salary_run`, `gnubok_calculate_salary_run`, `gnubok_book_salary_run`, `gnubok_generate_agi` | `payroll:read` / `:write` |
| Skatteverket | `gnubok_vat_declaration_submit`, `gnubok_agi_submit` | `skatteverket:write` |
| Godkännande | `gnubok_list_pending_operations`, `gnubok_approve_pending_operation` | `pending_operations:read` / `:approve` |
| Audit | `gnubok_audit_package`, `gnubok_export_sie`, `gnubok_query_journal` | `reports:read` |

Skrivverktygen stagar en `pending_operation` med förhandsvisning. Inget
bokförs förrän den godkänts, i appen under Granskning eller i chatten efter
ditt uttryckliga ja. Inlämningar till Skatteverket är dessutom klara först
när du signerat med BankID.

Behörigheterna sitter på anslutningen: de du lämnar ikryssade på
samtyckessidan, med din roll i bolaget som tak. Anslutningen når alla bolag
där din användare är medlem. `gnubok_list_companies` listar dem, och
`company_id` på ett anrop väljer bolag; utan det gäller anslutningens
standardbolag.

Verktygen heter `gnubok_*` som standard. Med `tool_namespace=accounted` i
adressen heter de `accounted_*`, vilket Claude Code-pluginet och produktens
egen guide använder. Det är samma verktyg.

## Installera i Claude.ai eller Claude Desktop

1. Inställningar → Connectors → Add custom connector.
2. Ange URL: `https://app.accounted.se/api/extensions/ext/mcp-server/mcp?auth=required` (utan `auth=required` föreslår dialogen "None" som autentisering och inloggningen öppnas aldrig).
3. Claude öppnar accounted-inloggningen i webbläsaren. Logga in och godkänn anslutningen.
4. Connectorn dyker upp i listan. Slå på den i de chattar där du vill ha den aktiv.

## Installera i ChatGPT

1. I ChatGPT på webben: Inställningar → Säkerhet och inloggning → slå på Utvecklarläge.
2. Gå till Plugins, välj + och skapa en app i utvecklarläge med adressen `https://app.accounted.se/api/extensions/ext/mcp-server/mcp`.
3. Starta en ny chatt, välj + → Utvecklarläge → appen, och logga in när ChatGPT frågar.

## Installera i Grok

1. På grok.com: Connectors → New Connector → Custom.
2. Ange URL: `https://app.accounted.se/api/extensions/ext/mcp-server/mcp?auth=required` (utan `auth=required` ser Grok servern som öppen och startar aldrig inloggningen).
3. Grok registrerar sig själv och öppnar accounted-inloggningen. Logga in och godkänn anslutningen.
4. Starta en ny chatt med connectorn påslagen.

## Installera i Claude Code

Det officiella pluginet ger både anslutningen och sju arbetsflöden
(bokföring, hälsokoll, månadsavslut, moms, lön, bokslut):

```text
/plugin marketplace add erp-mafia/accounted
/plugin install accounted@accounted
```

Bara anslutningen:

```bash
claude mcp add --transport http accounted "https://app.accounted.se/api/extensions/ext/mcp-server/mcp"
```

Logga sedan in via `/mcp`.

## Installera i Cursor

`~/.cursor/mcp.json` (globalt) eller `.cursor/mcp.json` (per projekt):

```json
{
  "mcpServers": {
    "accounted": {
      "url": "https://app.accounted.se/api/extensions/ext/mcp-server/mcp"
    }
  }
}
```

Logga in i webbläsaren när Cursor ber om det.

## Stdio-brygga med API-nyckel

För klienter som bara stödjer stdio (vissa egna agentmiljöer,
CI-pipelines) finns en lokal brygga via npm. Nya installationer använder
`accounted-mcp`:

```json
{
  "mcpServers": {
    "accounted": {
      "command": "npx",
      "args": ["-y", "accounted-mcp"],
      "env": {
        "ACCOUNTED_API_KEY": "gnubok_sk_..."
      }
    }
  }
}
```

Befintliga konfigurationer med `gnubok-mcp` och `GNUBOK_API_KEY` fungerar
oförändrade.

API-nyckeln skapas i app.accounted.se under Inställningar → API och MCP.
Nyckelvärdet börjar fortfarande med `gnubok_sk_`. Du väljer scopes per
nyckel och område (transaktioner, kunder, artiklar, fakturor, leverantörer,
rapporter, bokföring, löner, dokument, avstämning, Skatteverket,
godkännande med flera), och nyckelns scopes styr vilka verktyg som går att
anropa. En `gnubok_sk_test_*`-nyckel läser bolagets riktiga data men tvingar
varje skrivning till dry-run.

Lämpligt när maskinen som kör agenten inte kan öppna en webbläsare.

## Audit och behandlingshistorik

För revision och BFL-spårbarhet använder du
`gnubok_audit_package({ fiscal_period_id })`. Den producerar en zip för
räkenskapsåret med:

* SIE 4-fil
* Rapporter: saldobalans, resultat- och balansräkning, huvudbok, grundbok och moms (JSON och CSV)
* Underlagen, med ett manifest
* Behandlingshistoriken
* Systemdokumentationen för räkenskapsåret

Filen hämtas via en signerad länk som gäller i en timme.

## Sånt servern inte gör

* Servern kör ingen tredjepartskod. Egna skills och workflows körs alltid hos den som skickar anropet, inte hos oss.
* Servern stagar alltid skrivoperationer. Ett verifikat bokförs först när någon med rätt behörighet godkänt det, i [app.accounted.se](https://app.accounted.se) eller i chatten.
* Anslutningen når bara bolag där den inloggade användaren är medlem. Det kontrolleras på servern vid varje anrop.

## Versionering

OAuth-discoveryn följer RFC 8414 (Authorization Server Metadata),
RFC 9728 (Protected Resource Metadata) och RFC 7591 (Dynamic Client
Registration). Stdio-bryggorna på npm är `accounted-mcp@1.0.0` för nya
installationer och `gnubok-mcp@1.1.0` för befintliga konfigurationer, båda
under MIT. Servern är källkod under AGPL-3.0 på
[github.com/erp-mafia/accounted](https://github.com/erp-mafia/accounted).
